# DevChat 数据库设计

本文档以 `server-web/src/database/schema.sql` 为准，保留核心表和关系说明。

## 1. 数据库概览

- 类型：SQLite
- 驱动：sql.js
- 特点：轻量、单文件、适合当前单机部署模式

## 2. 核心表

### 2.1 用户与关系

- `users`：用户信息
- `friendships`：好友关系

### 2.2 聊天

- `chats`：聊天主体，类型包括 `direct`、`group`、`project`
- `chat_members`：聊天成员、角色、未读数、最后已读消息
- `messages`：聊天消息

### 2.3 项目协作

- `projects`：项目主表
- `project_members`：项目成员与角色
- `tasks`：任务
- `bugs`：缺陷
- `documents`：文档
- `document_comments`：文档评论
- `repositories`：代码仓库
- `project_prototypes`：项目原型稿

### 2.4 文件与附件

- `files`：上传文件元数据
- `message_attachments`：消息附件关联
- `document_attachments`：文档附件关联
- `bug_attachments`：缺陷附件关联

### 2.5 预留能力

- `ai_analyses`
- `ai_analysis_messages`

这两张表用于未来 AI 分析结果存储，但当前业务流程未正式启用。

## 3. 关键关系

- 一个项目有多个成员、任务、缺陷、文档、仓库、原型稿
- 一个聊天有多个成员和多条消息
- 一个项目最多关联一个项目聊天，聊天类型为 `project`
- 文件通过关联表挂接到消息、文档、缺陷，而不是使用多态字段

## 4. 当前实现中的几个要点

- `documents` 表已包含 `format` 字段，支持 `markdown` 和 `richtext`
- `bugs` 表包含 `images` 字段，用于保存缺陷截图信息
- 聊天未读数保存在 `chat_members.unread_count`
- 附件下载依赖 `files.file_path`

## 5. 结论

当前数据库设计已经覆盖聊天、项目协作、仓库管理、原型预览等主要功能，并且相对克制，适合继续在 SQLite 上迭代。
