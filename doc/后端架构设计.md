# DevChat 后端架构说明

本文档基于当前 `server-web/src` 的实际实现，不再描述未接入的中间件或外部服务。

## 1. 架构分层

- `routes`：定义 API 路由
- `controllers`：参数读取、响应输出
- `services`：业务规则和跨仓储协作
- `repositories`：直接操作 SQLite
- `websocket`：Socket.IO 实时消息与在线状态
- `database`：数据库初始化、迁移、备份、自动保存

## 2. 应用入口

- `src/server.ts`：启动数据库、执行迁移和种子、创建 HTTP 服务、挂载 WebSocket
- `src/app.ts`：注册中间件、API 路由、原型预览路由、错误处理

## 3. 中间件

- `helmet`：基础安全头
- `cors`：动态放行 localhost、127.0.0.1 和私网 `:5173` 开发来源，也支持环境变量覆盖
- `express-rate-limit`：登录、上传、通用接口限流
- `morgan + winston`：请求日志和业务日志
- `auth.middleware`：JWT 鉴权
- `permission.middleware`：项目成员权限校验

## 4. 核心模块

### 4.1 认证与用户

- 注册、登录、刷新、退出登录
- 用户资料查询与编辑
- 用户搜索与好友关系管理

### 4.2 聊天

- 私聊、群聊、项目群聊
- 消息发送、编辑、删除、搜索、已读标记
- 附件上传与下载
- 管理员拉人、踢人、退群
- 管理员退群后自动补管理员

### 4.3 项目

- 项目 CRUD
- 项目成员管理
- 项目任务、缺陷、文档、评论、仓库、原型稿管理
- 打开项目聊天时自动创建或复用项目群

### 4.4 仓库与原型

- 仓库模块通过 `GitLabService` 拉取 README、分支、Merge Requests
- 原型模块通过 zip 上传、解压和预览 key 访问静态文件
- 原型预览路由单独处理响应头，兼容 Axure 页面加载

## 5. WebSocket

- 使用 Socket.IO，和 HTTP 共用同一端口
- 连接时通过 JWT 校验身份
- 用户会加入个人房间和聊天房间
- 支持新消息广播、在线状态广播、输入中、已读通知

## 6. 数据与部署特点

- 数据库存储在本地 SQLite 文件
- 上传文件和原型解压文件存储在本地目录
- API 默认监听 `3000`
- 前端默认从当前浏览器主机名推断后端地址，便于换机部署

## 7. 当前没有的部分

- Redis 缓存
- Swagger / OpenAPI 自动文档
- 独立消息队列
- 完整 AI 流程接入

## 8. 结论

当前后端是一个标准的轻量分层 Node.js 服务，重点是快速实现 IM + 项目协作闭环，而不是复杂的分布式架构。
